Cleaner semantics — the trace stops carrying epoch-zero timestamps and phantom `missing_fraction=1.0` values pretending to be observations. Filed by `reviews/sdd-check-round-2-with-spec.md §3`. ## Decisions

*Architect-only, append-only.*

- **2026-08-09** — Project scope: Price-Space LLM v1 is a causal decoder transformer over 15-minute multi-channel market state on SPY, predicting a 32-bucket vol-normalized forward return distribution, run through a cost-aware simulator on a 2024-01-01 through 2025-06-30 held-out window. Success is defined by the pre-registered gates in `specs/product-spec-v4.md` §"Success gates for v1".

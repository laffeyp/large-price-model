# Signals v0.6 rationale

**Locked:** 2026-08-17 by Architect (Peter Laffey), via Sprint 080.
**Prior:** v0.5 (locked 2026-08-15 per Sprint 055, `NORMALIZER_DRIFT_MEASURED`).
**Delta:** two new tags; zero tags removed; zero payload types changed.

## What changed

**`TOKENIZED_ARTIFACT_WRITTEN`** (category: `tokenize`, stratum: `summary`).

Sprint 052 shipped the extended `.pt` tokenized artifact per tech-arch §5 and deferred a dedicated emit tag with a note in the docstring: *"Sprint 053 or a v0.5 vocab bump may add TOKENIZED_ARTIFACT_WRITTEN if needed."* Sprint 078 routed the write through `artifacts.write_versioned` + `.sha256` sidecar + `tokens.latest.pt` symlink; the artifact now has a stable version + hash to name. The tag closes the deferred emit surface. Fires once per `run_tokenizer_pt` call.

Payload: `run_id`, `path` (versioned), `sha256`, `n_channels`, `n_rows`, `mask_semantics` (Sprint 075 marker).

**`NORMALIZER_CHANNEL_UNDER_CLAMP`** (category: `feature`, stratum: `incident`).

Sprint 076 added the `warn_channels_under_clamp` opt-in helper. Sprint 079 promoted it to `fit_frozen_normalizer`'s `strict_std_clamp=True` default with `NormalizerStdClampViolation` raised on hits. Sprint 080 wires the signal-side surface: one emit per (channel, feature_index) where the fitted std sits below `std_clamp` on a non-exempt channel. The emits fire before the raise (in strict mode) or as pure warnings (in `strict_std_clamp=False` mode), so the trace records exactly which channels tripped the check regardless of the strict/lenient posture.

Payload: `run_id`, `channel`, `feature_index`, `std_value`, `std_clamp`.

## What did not change

- No payload types changed. No enum values added. No tags removed.
- Vocabulary count 56 → 58.
- Every prior version file (`signals/0.1.json` through `signals/0.5.json`) stays on disk per hard rule 12. `_vocab/0.6.json` is a symlink to `signals/0.6.json`; the write-integrity story is the same as prior locks.

## Migration notes

- No pre-v0.6 trace or artifact becomes invalid.
- Callers that catch `NormalizerStdClampViolation` continue to work; Sprint 080 layers the emit in front of the raise, not in place of it.
- Any emit site created before v0.6 that lacks these two tags stays valid — v0.6 is a strict superset.
- `load_vocabulary` default bumps from `"0.5.json"` to `"0.6.json"` in `src/price_space_llm/signals.py`. Callers that pin `"0.5.json"` (or earlier) continue to work; every prior file remains loadable.

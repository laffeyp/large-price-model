# Vocabulary v0.5 (locked 2026-08-15)

**One addition, no removals, no renames.**

## Change

Adds `NORMALIZER_DRIFT_MEASURED` in the `feature` category, `summary` stratum. Fires once per (channel, feature_index) during a drift-diagnostic run that compares training-partition vs holdout-partition distributions of normalized features.

Payload: `run_id, channel, feature_index, train_mean, train_std, holdout_mean, holdout_std, ks_statistic, p_value`.

## Rationale

Product-spec-v4.md line 251:
> "Track it as a failure mode. Fix: plot the normalized-feature distribution on the holdout against training."

The v0.4 vocab had `NORMALIZER_FITTED` + `NORMALIZER_STATE_WRITTEN` for the fit + write side of the frozen normalizer, but nothing for the *diagnostic* side. Sprint 054 wired the fit + write. Sprint 055 needs a signal home for the diagnostic. Without a dedicated tag, the diagnostic would either fabricate a fit into an unrelated tag or write nothing to the trace — both dishonest.

`reviews/full-review-sprints-041-050.md` § 3 item #8 flagged the missing diagnostic. Sprint 041's own aggregate spec-vs-code audit (BLACKBOARD entry 2026-08-13) listed the tag as a v0.4 candidate. Sprint 055 delivers it as v0.5 instead — v0.4 shipped with an existing tag set (Sprint 040 retraction removed `WANDB_UPLOAD_FAILED`) that this addition can no longer join.

## Hard rule 12: prior versions stay on disk

- `signals/0.1.json` through `signals/0.4.json` remain unchanged.
- `src/price_space_llm/_vocab/0.1.json` through `_vocab/0.4.json` remain unchanged.
- Any run that emitted against v0.4 stays interpretable via the v0.4 loader.

## Default loader version

`src/price_space_llm/signals.py::load_vocabulary` default flips from `"0.4.json"` to `"0.5.json"`. Callers who pin a version explicitly (currently: none — every callsite uses the default) are unaffected.

## Category + stratum choices

`feature` category groups this with NORMALIZER_FITTED + NORMALIZER_STATE_WRITTEN + FEATURE_COMPUTED + FEATURE_COMPUTATION_FAILED. `summary` stratum matches NORMALIZER_FITTED — one emit per unit of aggregate, not per bar.

## Field-type choices

Every numeric field is `float`. `ks_statistic ∈ [0, 1]` per KS definition. `p_value ∈ [0, 1]` per statistical convention. `feature_index: int` starts at 0 within the channel's F_c tensor width. `channel: str` matches the aligned-parquet `{channel_name}__{symbol}` convention rather than an entity_ref, because Sprint 055 does not add a new entity (the tag references `NormalizerState`).

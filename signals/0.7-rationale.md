# Signals v0.7 rationale

**Locked:** 2026-08-17 by Architect (Peter Laffey), via Sprint 084.
**Prior:** v0.6 (locked 2026-08-17 per Sprint 080).
**Delta:** two payload-field extensions; zero tags added; zero tags removed; zero payload types changed on unrelated tags.

## What changed

**`CONFIG_RESOLVED` gains six required fields.**

Sprint 073 landed model-size configs and Sprint 083 landed the mixer fusion. Both left `CONFIG_RESOLVED` unable to describe the resolved model. A trace reader could recover shape from `run_id` (`-{size}-c{N}-mix` infixes) plus a git SHA lookup of `configs/model/{size}.json`, but not from the payload alone. Hand-authored shapes via `--model-config PATH` did not encode the path in `run_id` at all. Two drift-watchlist entries (2026-08-16 Sprint 073 close; 2026-08-17 Sprint 083 close) named the gap.

Added fields:

- `d_model: enum<64|128|192|384|512>` — model width. `64` is the pre-Sprint-073 default; `128/192/384/512` match `configs/model/{xs,sm,md,lg}.json`.
- `n_layers: enum<4|6|8>` — transformer blocks per configs/model.
- `n_heads: enum<2|3|4|6|8>` — attention heads.
- `fusion: enum<sum|mixer>` — embedder shape per tech-arch § 10 ablation.
- `mixer_dim: int` — mixer hidden width. Ignored when `fusion='sum'`.
- `mixer_n_heads: int` — mixer attention heads. Ignored when `fusion='sum'`.

All required. `scripts/train.py` populates them from the resolved model + fusion axes; every training-run trace becomes self-describing.

**`TOKENIZED_ARTIFACT_WRITTEN` gains one required field.**

Sprint 083's live smoke exposed a mixer-on-un-normalized-features divergence class. Downstream trainers with `fusion='mixer'` must consume normalizer-applied artifacts. The signal-side surface for this contract needs a mechanical marker. Added:

- `normalized: bool` — True iff `run_tokenizer_pt` applied a frozen normalizer during the write. Downstream `run_training_feats(fusion='mixer')` refuses artifacts where the artifact's `meta["normalized"]` is False.

## Contract changes

- `CONFIG_RESOLVED.d_model / n_layers / n_heads / fusion / mixer_dim / mixer_n_heads` — required. Any pre-v0.7 emit site without them raises at emit time. The only emit site is `src/price_space_llm/config.py::load_config`; Sprint 084 updates it in the same commit to populate the fields.
- `TOKENIZED_ARTIFACT_WRITTEN.normalized` — required. Only emit site is `run_tokenizer_pt`; Sprint 084 updates it.
- `NORMALIZER_STATE_WRITTEN` and every other tag unchanged.

## Grammar-growth record

Both extensions are `PAYLOAD_FIELD_ADDED` proposals under PRINCIPLES.md. Adding a required field is a hard schema change: any prior emit site missing the field raises. The kit accepts this class of change on a fresh version lock; every consumer that pins `"0.7.json"` gets the new contract, every consumer that pins an earlier version gets the pre-v0.7 shape unchanged.

## Migration notes

- Pre-v0.7 traces on disk remain interpretable via their embedded `vocab_version` (`SESSION_INIT.vocab_version`).
- Consumers that pin `load_vocabulary("0.6.json")` continue to work; every prior file remains loadable.
- `scripts/train.py` populates the new `CONFIG_RESOLVED` fields from `TransformerConfig` / `MarketStateTransformerConfig` and the `--fusion / --model-size / --context-size` flags. A run under legacy defaults (`--model-size` absent, `--fusion` absent) emits `d_model=64, n_layers=4, n_heads=4, fusion="sum", mixer_dim=96, mixer_n_heads=2` — the defaults on `MarketStateTransformerConfig`.
- `run_tokenizer_pt` sets `meta["normalized"] = True` when the caller passes a `normalizer=...` kwarg; else False. `TOKENIZED_ARTIFACT_WRITTEN` picks up the value from `meta`.
